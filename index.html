ใบงานพร้อมพิมพ์

เลือกแบบ ตั้งค่า แล้วพิมพ์ลง A4 ได้ทันที มีเฉลยให้ครู

ตอนพิมพ์ให้เลือกกระดาษ A4 ขอบกระดาษ "ไม่มี" และปิดหัวกระดาษท้ายกระดาษของเบราว์เซอร์ ถ้าต้องการไฟล์ PDF ให้เลือกปลายทางเป็น "บันทึกเป็น PDF" ถ้ากดพิมพ์แล้วไม่มีอะไรเกิดขึ้น ให้เปิดเว็บนี้ใน Chrome หรือ Safari แทนการเปิดจากในแอป Facebook หรือ LINE

แจ้งปัญหาหรือเสนอแนะทาง Facebookใช้ฟรี ไม่ต้องสมัครสมาชิกเครื่องมืออื่นจากผู้จัดทำเดียวกัน: กำไรแม่ค้าสูตรเปิดร้าน
วิธีใช้ ใบงานพร้อมพิมพ์

สร้างใบงาน

  1. เลือกประเภทใบงาน: บวก ลบ คูณ หาร, คัดลายมือ, จับคู่คำศัพท์, สูตรคูณ โจทย์ปัญหา บอกเวลา เปรียบเทียบจำนวน แบบรูปจำนวน หรือเศษส่วน และยังมีตารางเรียนกับใบเช็กชื่อสำหรับงานประจำห้อง
  2. แก้ชื่อโรงเรียน ชื่อใบงาน และคำชี้แจงตามต้องการ
  3. ตั้งค่าระดับชั้น จำนวนข้อ หรือพิมพ์เนื้อหาของคุณเอง ตัวอย่างด้านขวาจะเปลี่ยนตามทันที
  4. ถ้าอยากได้โจทย์ชุดใหม่ กดสุ่มโจทย์ใหม่
  5. เลือกจำนวนชุดได้ถึง 6 ชุดที่โจทย์ไม่ซ้ำกัน เหมาะสำหรับแจกนักเรียนที่นั่งติดกัน และเลือกกรอบตกแต่งได้
  6. ติ๊กแนบหน้าเฉลย ถ้าต้องการเฉลยสำหรับครู

พิมพ์หรือบันทึกเป็น PDF

  1. กดพิมพ์ใบงาน
  2. เลือกขนาดกระดาษ A4 ตั้งขอบกระดาษเป็น "ไม่มี" และปิดหัวกระดาษท้ายกระดาษของเบราว์เซอร์
  3. ถ้าต้องการไฟล์ ให้เลือกปลายทางเป็น "บันทึกเป็น PDF"

ข้อแนะนำ

  • ตรวจโจทย์และเฉลยอีกครั้งก่อนแจกนักเรียน
  • ใบงานจับคู่ ให้พิมพ์คำศัพท์บรรทัดละ 1 คู่ คั่นด้วยเครื่องหมาย = เช่น cat = แมว หรือกดเลือกชุดคำศัพท์สำเร็จรูป 13 หมวด
นโยบายความเป็นส่วนตัวและความปลอดภัยของข้อมูล

ปรับปรุงล่าสุด 15 พฤศจิกายน 2569

ใบงานพร้อมพิมพ์เป็นเครื่องมือที่ทำงานในเบราว์เซอร์ของคุณทั้งหมด ไม่มีระบบสมาชิก และไม่มีเซิร์ฟเวอร์ของเราที่รับหรือเก็บข้อมูลที่คุณกรอก

ข้อมูลที่เว็บนี้เก็บ

  • เว็บนี้ไม่บันทึกข้อมูลใดไว้เลย ชื่อโรงเรียน เนื้อหา และโจทย์ที่สร้าง จะหายไปเมื่อปิดหรือรีเฟรชหน้าเว็บ

สิ่งที่เว็บนี้ไม่ทำ

  • ไม่มีการสมัครสมาชิก ไม่ขออีเมลหรือรหัสผ่านของคุณ
  • ไม่ส่งข้อมูลที่คุณกรอกออกไปนอกเครื่อง
  • ไม่ใช้คุกกี้ติดตาม ไม่มีโฆษณา และไม่มีระบบวิเคราะห์ผู้เข้าชม ณ วันที่ปรับปรุงนโยบายนี้

ผู้ให้บริการภายนอก

  • เว็บนี้ฝากไฟล์ไว้กับ GitHub Pages ซึ่งอาจบันทึกข้อมูลทางเทคนิคของการเข้าชม เช่น หมายเลข IP ตามนโยบายของ GitHub
  • ตัวอักษรบนหน้าเว็บโหลดจาก Google Fonts เบราว์เซอร์ของคุณจึงติดต่อเซิร์ฟเวอร์ของ Google เพื่อดาวน์โหลดไฟล์ตัวอักษร

การดูแลข้อมูลของคุณเอง

  • ไม่ควรพิมพ์ชื่อจริงหรือข้อมูลส่วนตัวของนักเรียนลงในใบงานที่จะเผยแพร่ต่อ
  • ลบข้อมูลทั้งหมดได้ด้วยการล้างข้อมูลเว็บไซต์นี้ในการตั้งค่าของเบราว์เซอร์
  • ข้อมูลไม่ได้สำรองไว้ที่ใด ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ข้อมูลจะหายไป

ข้อจำกัดของผลลัพธ์

ตัวเลขและเนื้อหาที่เว็บนี้แสดงเป็นการประมาณเพื่อช่วยตัดสินใจ กรุณาตรวจสอบกับข้อมูลจริงของคุณก่อนนำไปใช้ ผู้จัดทำไม่รับผิดชอบต่อความเสียหายที่เกิดจากการนำผลลัพธ์ไปใช้โดยไม่ตรวจสอบ

การเปลี่ยนแปลงและการติดต่อ

หากในอนาคตมีการเพิ่มระบบนับผู้เข้าชม โฆษณา หรือการเก็บข้อมูลแบบอื่น นโยบายนี้จะได้รับการปรับปรุงก่อนเปิดใช้ ติดต่อผู้จัดทำได้ทาง Facebook ของผู้จัดทำ
